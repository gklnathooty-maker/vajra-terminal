# Chartink Integration Policy

Chartink is valuable as a reference for scanner UX and technical/fundamental
filter concepts. Its public guide documents indicators, offsets, comparisons,
grouped filters and min/max functions.

This project does not implement scraping or reverse-engineering of Chartink.

If a future official API/licensing arrangement is obtained, a separate adapter
may be added behind the provider interface.

Otherwise the scanner is evaluated using the application's licensed market data.

This approach reduces vendor lock-in and avoids building a commercial product
around undocumented web endpoints.
